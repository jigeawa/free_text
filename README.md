## 操作过程 (how to use)
  由于这个是比较类似Windows的cmd操作的 所以一些经常使用gui的人貌似容易看不懂 所以写个教程看一下
1. 打开你需要爬取的网站
2. 找到网址栏
3. 复制网址
4. 打开作文爬取器(v0.9.3).py (更推荐使用这个版本 bug 更少)
5. 粘贴你刚刚复制的网址
6. 回车
7. 输入文件名
8. 回车
9. 发现保存成功  回车退出
10. 查看当前文件目录下的txt文档
11. 双击打开
12. ctrl + a 全选 复制 随后可以粘贴到任何地方打印

# 警告 (WARINING) ⚠️
### 这个项目实测无法爬取诸如**360文库、百度文库**等防护严密的网站 不过对付一些**小型网站**还是比较轻松的
## 使用场景 (scenes)
### 当你在老师布置了摘抄作业 想要复制之后打印出来摘抄的时候 好不容易打开一个摘抄网站 却显示需要VIP才能摘抄 但是你并不想充钱 此时就可以使用这个项目 当然 这个项目的用途绝对不止这么点 至于其他用处 使用场景 就等着你去慢慢发现啦~
